## 为什么

当前应用主要按照浅色样式实现，在低光环境下使用不够舒适，也无法匹配偏好系统暗色主题的用户。添加暗黑模式可以提升可访问性、视觉舒适度，并让应用更符合 Android 平台主题行为。

## 变更内容

- 为应用页面添加暗色主题支持，包括 Compose 主题色和 XML/View 体系的资源。
- 默认支持跟随系统主题，让应用可以随设备设置自动切换。
- 在合适位置提供用户可见的主题偏好入口，可选择浅色、暗色或跟随系统。
- 确保关键自定义 View 和功能页面在浅色、暗色主题下都清晰可读。

## 能力范围

### 新增能力
- `dark-mode`：覆盖应用级暗黑模式行为、主题偏好处理，以及浅色/暗色渲染下的视觉要求。

## 影响范围

- 受影响代码：`app/src/main/java/com/example/testai/ui/theme/` 下的主题定义、`app/src/main/res/` 下的 Android 资源、使用 XML 布局的 Activity、Compose 入口，以及存在硬编码颜色的自定义 View。
- API/依赖：预计不引入外部 API 变更；可使用现有 AndroidX/AppCompat 夜间模式 API。
- 系统行为：Android 运行时主题配置和持久化的用户主题偏好。
